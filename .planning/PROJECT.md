# Nirman Infrastructure Ratnagiri - Website Project

## Project Vision & Brief
A world-class, premium architectural real estate builder & construction corporate website for **Nirman Infrastructure Ratnagiri**, located in Ratnagiri, Maharashtra.
The website caters to homeowners planning residential construction, property buyers, real estate investors, commercial developers, and local clients looking for trustworthy turnkey construction in the Konkan / Ratnagiri region.

## Brand Identity & Aesthetic
- **Brand Colors**: Deep Architectural Slate/Navy (`#0B132B`), Concrete Warm Off-White (`#F8FAFC`), Logo Electric Cyan/Blue (`#0284C7`), Logo Growth Green (`#16A34A`), Architectural Bronze/Ochre accents.
- **Logo Integration**: Main Header & Mobile Navigation features the official Nirman Infrastructure brand identity with star and dual-pillar mark ("ha header la logo pahije main").
- **Visual Tone**: Architectural, modern, minimal, trustworthy, structural, interactive, and high-end Awwwards-inspired engineering aesthetic.

## Tech Stack
- React 19 + Vite
- Tailwind CSS
- shadcn/ui components
- GSAP + ScrollTrigger
- Motion / Framer Motion
- Lenis smooth scrolling
- React Three Fiber + Drei (interactive 3D architectural geometric tower/blueprint structure)
- Lucide React icons
